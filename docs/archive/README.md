# Arquivo Histórico

Este diretório guarda material que continua útil como contexto, mas não deve ser a primeira leitura de quem está tentando entender o projeto hoje.

- `changelog/`: evolução por versão
- `backlog/`: planos antigos e pipelines de melhoria
- `blog/`: narrativas e artigos do processo de construção
- `legacy-docs/`: documentos técnicos antigos

Para o estado atual e direção do projeto, volte para o diretório pai `docs/`.
