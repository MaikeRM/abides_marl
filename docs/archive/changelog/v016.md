# Changelog

## v0.1.6 - 2026-03-12

### Added

- **Baseline reproduzível do simulador**:
  - formalização do cenário padrão em `app/core/runner.py` via `BaselineScenario`
  - execução batch do baseline com métricas mínimas em `uv run python -m app.core.runner`
  - documentação do cenário padrão em `docs/baseline-scenario.md`

- **Suíte de sanidade**:
  - testes para `Kernel`, `ExchangeAgent`, contabilidade dos agentes e reprodutibilidade do baseline em `tests/`

### Changed

- **Prioridade ativa do projeto**:
  - `docs/next-steps.md` passa a tratar a interface RL como prioridade principal, já que o baseline foi fechado

### Fixed

- **Contabilidade de ordens resting**:
  - mensagens `EXECUTION` agora carregam `order_id` quando uma ordem resting é executada, permitindo reconciliar `active_orders`

- **Invariantes do livro**:
  - `ExchangeAgent` agora valida coerência entre heaps, `_order_map`, quantidade positiva e ausência de book cruzado/locked após mutações
