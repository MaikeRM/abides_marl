# Changelog

## v0.1.5 - 2026-02-25

### Added

- **Migração do Dashboard para DearPyGui (Frontend API)**:
  - Substituição completa da interface textual (`Textual`) por uma interface gráfica (GUI) baseada em `DearPyGui` (`app/main.py`), suportando maior frequência atualização gráfica (HFT dashboards).
  - Nova aba interativa ("LOB Heatmap") projetada exclusivamente para focar na renderização visual do livro de ofertas.
  - Ideação e estruturação da nova aba "Agent Tracker" para monitorar a visão geral dos tipos de agentes.

- **Order Book Viewer (Dashboard)**:
  - Reestruturação de layout, adicionando alinhamento customizado de colunas para informações de quantidade e preços de Bid e Ask.
  - Aumento da profundidade geral visível (Order Book Depth) no lado do cliente para mostrar mais níveis de mercado simultaneamente de forma estável.

- **Aprimoramento do Limit Order Book (LOB) Heatmap**:
  - Implementação de botões de presets customizados do eixo X, servindo dados e comportamentos nas seleções de 100, 500 e 1000 intervalos.
  - Exploradas implementações matemáticas alternativas para mitigar as antigas matrizes esparsas por um mapa real visualmente contínuo e mais agradável (fuga visual de Scatter Plots).

### Changed

- **Stack Front-end HFT**:
  - Adoção sistemática do C++ backend bindings do DearPyGui (`dpg`) no lugar principal de exibição, visando aguentar processamentos densos das execuções em Loop.

### Fixed

- **Visualização Borrada / Heatmap Trails**:
  - Correção do bug de renderização no Limite Order Book Heatmap, eliminando os vestígios (trails) ou sobreposições geradas pelo redesenho de estados não totalmente limpos durante o refresh visual cíclico.
